# HODI PASS · HODIPARKING 통합

HODIPARKING 1.0.49부터 차량 조회·사진·hodi_00001 할인권·방문권 기능이 기존 서비스 안에서 함께 동작합니다. 별도 연결 프로그램 설치는 필요 없습니다.

기존 HODIPARKING의 업데이트 메뉴를 사용하세요. 같은 Windows 사용자의 HOPASS 출입관제 서버와 자동 연결합니다. 서버 PC가 다르면 HOPASS 관리자 사이트에서 연결 코드를 발급하고 HODIPARKING 설정의 HODI PASS 메뉴에 입력하세요.

현재 등록된 활성 사원은 웹 할인권 권한을 받았습니다. 이후 신규 사원은 HOPASS 관리자에서 지정합니다. SK쉴더스 자격 증명은 기존 HODIPARKING 설정을 재사용하며 앱으로 전송하지 않습니다.

이전 별도 연결 프로그램 ZIP은 과거 버전 보관용이며 새로 설치하지 않습니다.
