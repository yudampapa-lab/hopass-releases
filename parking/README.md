# HODI PASS 주차 연결 프로그램 0.1.0

HODIPARKING이 설치되어 있고 SK쉴더스 로그인이 정상 동작하는 운영 PC에서 설치합니다. 기존 HODIPARKING을 설치한 Windows 사용자로 실행하세요.

1. HOPASS 서버를 0.8.3 이상으로 업데이트합니다.
2. HOPASS 관리자 사이트의 **방문 차량 · 주차 할인 권한**에서 사용할 사원만 체크합니다.
3. **HODIPARKING 연결 코드 발급**을 누릅니다.
4. 이 폴더의 `Install.cmd`를 실행하고 HODIPARKING 설치 폴더 및 연결 코드를 입력합니다.
5. 관리자 사이트에서 **HODIPARKING 연결됨**을 확인합니다.

할인권 계정은 `hodi_00001`입니다. 계정의 내부 번호는 SK쉴더스에서 확인하여 사용하며, 다른 계정으로 대체하지 않습니다. 공식 할인권 적용 API가 잔여량을 차감합니다. 별도로 재고를 한 번 더 차감하지 않습니다.

SK쉴더스 비밀번호는 기존 `data/sk-credentials.dat`에서 현재 Windows 사용자의 DPAPI로 읽습니다. 앱이나 중계 서버에 전송하지 않습니다. 연결 토큰도 Windows 사용자에게 묶여 암호화되어 보관됩니다. Windows 로그인 시 자동으로 실행됩니다.

빈 번호 검색은 현재 주차 중인 10일 미만 차량만 표시합니다. 번호 일부를 입력하면 기간 제한 없이 일치 차량을 조회합니다. 방문권 등록에는 전체 차량번호가 필요합니다. 문자나 출입 URL은 발송하지 않습니다.

통신이 끊겨 할인·등록 결과가 불확실하면 재실행하지 않습니다. 관리자가 SK쉴더스에서 실제 적용 여부를 확인한 뒤 HOPASS 관리자 사이트의 처리 내역에서 **적용 확인 / 미적용 확인**으로 정리합니다. 이 버튼 자체는 할인권을 사용하지 않습니다.

앱 0.9.78 이상이 필요합니다. 설치 후 관리자가 허용한 사원만 차량 조회·사진·할인권·방문권 메뉴를 사용할 수 있습니다. 실제 할인권 사용과 방문권 등록은 사용자의 적용 버튼으로만 실행됩니다.
